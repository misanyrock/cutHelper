# 工作台设计规范

参考：workspace.png（用户确认的 1536 × 1024 概念图）。

- 白色页头，冷灰 #f6f8fb 背景、#f8fafc 面板、#20242c 正文、#009a8e 主色、浅红静音区；不使用渐变。
- 系统中文字体；品牌 28px，区块标题 20px，操作 14px，辅助信息 11–12px；8–10px 圆角、细边框。
- 布局：静音列表 / 16:9 媒体与播放控制 / 参数；全宽波形与选中区间；底部本地处理状态。
- 组件：按钮、参数滑杆、片段行、互斥开关、预览切换、波形、导出菜单。图标使用 Lucide 线形图标；品牌使用可缩放播放标记。
- 文案以概念图标题、参数、导出项为准；额外的导入空态、保存/打开、取消、错误、变帧率提示用于完成既定工作流。
- 有意修正：每段保留/删除互斥；最短停顿为秒；统计必须来自区间；原片画面来自真实素材，初始不加载虚构访谈；系统窗口边框使用 Electron 系统默认。
- 响应式：小桌面收窄侧栏；950px 以下参数下移；640px 以下纵向堆叠。实际桌面窗口最小 1000 × 720。

## 实现对照

已通过真实 Electron 工作台截图与概念图对照：三栏与全宽时间线结构、浅色底与青绿/浅红语义色、标题和操作字体层级、按钮与面板圆角、导出菜单与波形标记。概念图数字与访谈画面由真实素材和计算值替代，互斥选择和秒数单位按确认意见修正。补充的保存/打开入口、任务状态、媒体空态及导入说明属于已规划的功能状态。

验证工具：未提供 Browser 插件，使用 Playwright 测试真实 Electron 与 Chrome 窄屏；Electron 原生 capturePage 截图规避 Mac 上 CDP 截图超时。桌面内容尺寸 1536 × 1024，Chrome 窄屏 390 × 844；检查控制台、横向溢出和实际播放。截图与测试素材不纳入源码提交。

## 图标更新

应用标识更新为青绿色底、白色播放符号与斜向剪切断口。矢量源文件为 `public/icon.svg`，页头、favicon、Dock 与安装包使用同一源设计；`npm run icons` 可重建各尺寸 PNG、ICNS 和 ICO。README 中的应用截图必须来自更新后实际运行的桌面工作台。

## v0.2.0 文字剪辑

保留原有浅色、青绿与三栏结构，左侧新增「文字 / 静音」切换；文字模式适当加宽左栏。模型状态、语言和转写入口位于段落列表上方，支持勾选、连续选择、删除线、修正文案及撤销；紫色波形区域表示文字删除，与粉色静音删除区分。桌面高窗口固定工作台高度，段落列表内部滚动，确保预览、参数、波形和底部状态均可见。

实际验证使用本地 small 模型与普通话合成语音，检查了点击定位、播放高亮、连续选择、删除/恢复/撤销、字幕修正、SRT 重映射、项目持久化，以及静音删除与文字恢复的覆盖提示。原有静音粗剪流程另外回归验证。
